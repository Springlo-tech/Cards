🎄 Experiência de Natal em AR - Velas Aromáticas
Este projeto utiliza a tecnologia de Realidade Aumentada Web (WebAR) para transformar velas aromáticas em uma experiência interativa de Natal. 

🚀 Sobre o Projeto
A experiência foi desenvolvida para uma cliente que buscava um diferencial tecnológico para seus produtos artesanais. O objetivo era unir o conforto sensorial das velas com a magia digital da AR.

O que acontece na experiência:
Rastreamento de Imagem: Utiliza o framework MindAR para detectar o marcador no rótulo.

Animação 3D: Um boneco de neve animado surge sobre o produto.

Mensagem Personalizada: Exibição de uma saudação natalina em alemão, atendendo ao pedido específico da cliente.

Trilha Sonora: Música temática de Natal integrada para completar a imersão.

🛠️ Tecnologias Utilizadas
MindAR - Framework para rastreamento de imagem e AR.

A-Frame - Framework web para construção de cenas 3D/VR.

HTML5/JavaScript - Estrutura e lógica da aplicação.

GitHub Pages - Hospedagem da experiência para acesso rápido via QR Code.

📦 Como Visualizar
Aponte a câmera do seu celular para o QR Code .

Permita o acesso à câmera no navegador.

Direcione a câmera para a arte do rótulo da vela.

Divirta-se com a animação e a música!
